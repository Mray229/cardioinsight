# CardioInsight

An educational cardiovascular risk estimator — one module of a broader "AI-powered
healthy aging platform" concept, inspired by EPQ research into AI-powered wearable
devices for cardiovascular disease detection.

**This is a prototype for educational purposes only. It is not a diagnostic tool and
does not replace professional medical advice.**

## What it does

Users enter basic health information (age, sex, blood pressure, resting heart rate,
activity level, smoking status, diabetes status, family history, BMI, cholesterol).
A logistic regression model estimates cardiovascular risk and explains which factors
are contributing most, using the model's own coefficients as a simple, interpretable
feature-importance view.

## Files

- `app.py` — Streamlit web app
- `train_model.py` — trains the model on a synthetic dataset built from established
  cardiovascular risk-factor relationships (age, blood pressure, smoking, diabetes,
  family history, etc.)
- `cardio_model.joblib` — trained model + scaler (generated by `train_model.py`)
- `cardio_synthetic_dataset.csv` — the training data used

## Deploying to Hugging Face Spaces (free)

1. Create a free account at huggingface.co
2. Click "New Space" → choose **Streamlit** as the SDK
3. Upload `app.py`, `requirements.txt`, `cardio_model.joblib`, and this `README.md`
4. The Space builds automatically and gives you a public link like
   `https://huggingface.co/spaces/<your-username>/cardioinsight`
